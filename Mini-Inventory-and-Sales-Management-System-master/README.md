# 🏭 Manufacturing Production & Quality Management System

A web-based **Manufacturing Production & Quality Management System** developed using **PHP (CodeIgniter), MySQL/SQLite, Bootstrap, and JavaScript**. The system helps manufacturing industries streamline production planning, inventory control, quality inspections, and sales operations through an intuitive dashboard.

---

## 📌 Overview

This application is designed to improve manufacturing efficiency by managing products, production workflows, inventory, transactions, and quality inspections in a centralized platform. It provides real-time insights through analytics and reporting to support operational decision-making.

## 🚀 Installation

1. Clone the repository

```bash
git clone https://github.com/yourusername/manufacturing-production-quality-management-system.git
```

2. Move the project to your local web server (`htdocs` or `www`).

3. Create a MySQL database.

4. Import the provided SQL file.

5. Configure your database credentials in

```
application/config/database.php
```

6. Enable **mod_rewrite** in Apache.

7. Configure the base URL in

```
application/config/config.php
```

8. Start Apache and MySQL.

9. Open

```
http://localhost/manufacturing-production-quality-management-system
```
